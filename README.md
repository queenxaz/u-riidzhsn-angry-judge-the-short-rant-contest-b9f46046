A short, funny rant about the smallest everyday betrayal: a printer that
only jams when it matters.

## The entry

**Judge, my printer only jams when the deadline is five minutes away. All week it prints blank pages, test pages, a photo of someone's cat — then the one document that matters, it eats it, blinks red, and dares me to open the tray like I'm defusing a bomb. I pay for ink by the drop and it drinks like it's at an open bar.**

## How it works

`main.py` writes the entry text to `/output/entry.txt` (or
`$MAKEFUN_OUTPUT_DIR/entry.txt` when set). No network, no randomness, no
arguments: the entry is fixed, so every run produces the same bytes.
